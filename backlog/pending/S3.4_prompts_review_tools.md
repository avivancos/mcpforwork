## Goal

The remaining MCP prompts (behavioral contracts for the client) and the review

## Spec

- `services/review.py`: `approve_match(uow, user_id, finding_id)` → status
  'approved' (only from new/review states; audited); `discard_match(uow,
  user_id, finding_id, reason?)` → status 'discarded' (audited). Unknown/foreign
  finding → `{error}`. check_seen already reports discarded findings.
- MCP tools `approve_match`, `discard_match`.
- Prompts: `/setup` (Tier-1 interview → update_profile/add_achievements/
  set_style_profile; <3 min), `/review` (list_matches → approve/discard loop),
  `/apply` (S3 scope: get_generation_brief → draft honoring honesty_rules →
  submit_asset → ats_coverage_check → iterate; the human sends/submits —
  browser-apply orchestration is Sprint 4).
- Prompts state the invariants: never fabricate beyond facts_inventory; never
  auto-submit.
