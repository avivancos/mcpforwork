# S3.3 — ats_coverage_check (deterministic, zero LLM)

**Epic:** Sprint 3 — Assets: briefs + honesty engine
**Estimated effort:** ~3 h
**State:** pending

## Goal

Deterministic server-side check: posting keywords vs asset text → covered /
missing-but-have / genuine-gap. Flags real gaps WITHOUT keyword stuffing —
the honesty engine's teeth (sprint demo gate).

## Spec

- `domain/coverage.py` (PURE): `coverage_check(keywords, asset_text,
  facts_text) -> {covered[], missing_but_have[], genuine_gaps[], coverage_pct}`.
  A keyword is: covered if present in the asset (case/plural-insensitive
  simple stem); missing_but_have if absent from the asset but present in the
  facts inventory text (profile/achievements/cv) — the drafter COULD truthfully
  add it; genuine_gap if in neither — must be acknowledged, never stuffed.
- `services/coverage.py`: `ats_coverage_check(uow, user_id, finding_id,
  asset_id)` — loads the finding's keywords (extract_keywords), the asset, and
  the profile facts; returns the domain result + next_action.
- MCP tool `ats_coverage_check(finding_id, asset_id)`.
