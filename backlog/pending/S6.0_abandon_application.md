# S6.0 — abandon_application tool (close stuck open sessions)

**Epic:** Apply orchestration follow-up (S4 gate)
**Estimated effort:** ~1 h
**State:** pending

## Goal
An application the human declines to submit is currently stuck open forever
(start_application perpetually re-opens it; reports rejected outside filling).
Add `abandon_application(application_id, reason?)`: any open state → abandoned
(via can_transition), audited; start_application then creates a fresh session.

## Definition of Done
- [ ] abandon from filling/awaiting_human/submit_requested; rejected from
      submitted/verified; audited; foreign id rejected
- [ ] after abandon, start_application creates a NEW application
- [ ] Tool-layer test with fresh-connection check; gate 4/4
