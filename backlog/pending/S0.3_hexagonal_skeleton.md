## Goal

The §Architecture spec layout exists as code and its boundary rules fail the
build when violated — architecture drift becomes impossible to merge, not a
review comment.

## Spec

- Packages `src/mcpforwork/{domain,services,ports,adapters,entrypoints,packs}`,
  each `__init__.py` docstring stating the layer's boundary rule. No
  speculative subpackages (rule of two — `adapters/db/` arrives with S1.1).
- import-linter contracts in `pyproject.toml`:
  1. domain imports no other layer;
  2. services never import adapters/entrypoints;
  3. ports are pure seams (no services/adapters/entrypoints);
  4. no `openai`/`anthropic` importable from domain/services/ports/packs.
  (Entrypoint-independence contract deferred until a second entrypoint
  exists — noted for S2.1.)
- `.github/workflows/ci.yml`: uv sync --locked → ruff format --check → ruff
  check → lint-imports → consent-verb grep gate (`submit_authorized` only
  under `src/mcpforwork/services/`) → pytest.
