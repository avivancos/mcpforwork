# S1.4 — Dedup engine port: canonical_url, hashes, check_seen

**Epic:** Sprint 1 — Data core (organ transplants)
**Estimated effort:** ~4 h

## Goal

The hardest-won correctness in the donor repo, transplanted with its tests:
canonical URL normalization, dedup hashing, the `external_applications`
table, and `check_seen` — the gate every apply flow runs through.

## Spec

**Donor (read-only reference):** `~/Desarrollo/startup-jobs-radar/`
- `src/radar/urls.py` (191 LOC) — `canonical_url`: pure-stdlib leaf, ZERO
  radar imports. Port near-verbatim into `domain/urls.py`: https force,
  www/port strip, tracking-param denylist + `utm_` prefix, sorted query,
  ATS-shape canonicalization (LinkedIn, Greenhouse, Lever, Ashby, Workable,
  SmartRecruiters, Teamtailor). Idempotence is the contract:
  `canonical_url(canonical_url(x)) == canonical_url(x)`.
- `src/radar/services/dedup.py` (457 LOC) — port the public API MINUS the
  review-service delegation: `dedup_hash(url)`, `check_seen(...)`,
  `record_application(...)`, `recompute_hashes(...)`.
  **Cut for the port:** the `record_application(job_id=…)` path that
  delegates to `review.approve_job` (drags review/profiles/pagination; the
  approve flow arrives in S3.4). `record_application` here takes explicit
  args (url/title/company/channel/method/notes/applied_at) and writes the
  dedup hash + audit row.
- Schema: `external_applications` table + dedup-hash columns (donor
  migrations; see also `009_widen_findings_dedup_pg.sql` for the widened
  matching).
- Tests to port: `tests/test_dedup_canonical.py`, `test_dedup_tracking.py`,
  `test_dedup_backfill.py`, `test_dedup_persist_cross_table.py` (adapt table
  names to the new schema).

**Placement:** pure logic (`canonical_url`, `dedup_hash`) in `domain/`;
DB-touching operations (`check_seen`, `record_application`,
`recompute_hashes`) in `services/dedup.py`.
