# S6.6b — Parity API: match action endpoints + profile POST

**Epic:** Sprint 6 / self-host E2E — API parity (Phase 1 of the E2E plan)
**Estimated effort:** ~3 h

## Goal

The dashboard's low-risk writes hit real endpoints:
`POST /v1/matches/{id}/approve|discard|restore|outcome` and
`POST /v1/profile` — each delegating to an existing service (plus the one
missing service function, `restore_match`).

## Spec

- `services/review.py`: add `restore_match(uow, user_id, finding_id)` —
  discarded → new, status-guarded in the UPDATE predicate (concurrent-safe
  like approve_match), audited.
- Routes in `entrypoints/api/app.py` (all require the session cookie):
  - `POST /v1/matches/{id}/approve` → `review.approve_match`
  - `POST /v1/matches/{id}/discard` → `review.discard_match` (body `reason?`)
  - `POST /v1/matches/{id}/restore` → `review.restore_match`
  - `POST /v1/matches/{id}/outcome` — body `{"outcome": web vocabulary}`;
    map `no_response` → `no_reply` (the rest pass through), resolve the
    finding's latest application, delegate to `apply.record_outcome`.
    Service `error` results → 400 (invalid transition) or 404 (unknown or
    foreign match — never distinguish).
  - `POST /v1/profile` — map the `types.ts` Profile patch onto existing
    profile columns via `profiles.update_profile`; NEVER add schema for a
    display field. Mapping: name→full_name, email→contact_email,
    headline→career_narrative, targetRole→target_titles[0..1],
    seniority→seniority (lowercased enum), employmentType→employment_types
    (display↔enum), workMode→work_modes, languages→languages (split "·"),
    cities→city (first entry; the intake model has no target-cities column —
    collapse documented). Display-only fields with no column are ignored by
    design: workRights, salaryFloor (free-formatted strings), tier1Step
    (derived, not writable).
  - `GET /v1/profile` — ALIGN the response to the types.ts `Profile` shape
    (the S6.1 slice returned raw columns; the web cannot render them). Fresh
    user (no profile) → default empty shape with tier1Step 1. tier1Step
    derived: no profile→1, tier-1 gaps open→2, none→4. Recorded deviation
    from the card's original POST-only scope (seam drift fix).
- 204 on success (the web's `call` maps 204 → undefined), 400 on service
  errors, 401 unauthenticated, 404 unknown/foreign match.
