# S0.4 — Zero-mocks test harness conventions

**Epic:** Sprint 0 — Foundations
**Estimated effort:** ~1 h

## Goal

The testing conventions every future card relies on exist and are themselves
tested: real SQLite at tmp_path, live-Postgres marker, pytest-httpserver —
the no-mocks quality bar ported from startup-jobs-radar's conftest patterns.

## Spec

- `tests/conftest.py`: `conn` fixture — REAL SQLite file at `tmp_path` (never
  `:memory:`, never a mock), `sqlite3.Row` factory, `PRAGMA foreign_keys=ON`,
  `busy_timeout`. Docstring documents the postgres-param pattern
  (`pytest.param("postgres", marks=pytest.mark.live)`) to be instantiated in
  S1.2.
- pytest config: `live` marker registered; `addopts = "-m 'not live'"`.
- Harness self-tests: package imports with version; the `conn` fixture rejects
  an FK-violating insert (proving PRAGMA enforcement — the behavior migration
  tests depend on).
- Donor reference: `startup-jobs-radar/tests/conftest.py` (fixtures `conn`,
  `stripe_httpserver`, `make_stripe_sig`, live-param pattern).

## Improvements noted

- Gate P1 (test-auditor): the harness now asserts the fixture's backing file
  via `PRAGMA database_list` — a `:memory:` mutant of the fixture no longer
  survives the suite. `busy_timeout` asserted too.
- `pytest.raises` idiom adopted so future cards copy the canonical pattern
  (gate P3).
- `check_same_thread=False` dropped — unspecced, no threaded consumer;
  reintroduce deliberately with the card that needs it (gate P3 from
  simplicity + security).
