# W4.1 — SEO/marketing infra + error surfaces

**Epic:** Web / public site (commercial v1)
**Estimated effort:** ~2.5 h

> Web-track card, branch web-v1. The public site has no favicon, OG/Twitter
> metadata, robots, sitemap, manifest, or custom 404/error pages. A commercial
> site needs these to be shareable and indexable.

## Goal

Add the SEO/marketing infrastructure and error surfaces, with a single
site-origin config, using only Next.js built-ins (no new dependency).

## Spec

- **Site origin:** `web/src/lib/site.ts` → `SITE_URL = process.env.NEXT_PUBLIC_SITE_URL ?? "https://mcpfor.work"`. Used by metadataBase, robots, sitemap, manifest.
- **Metadata:** set `metadataBase` + default `openGraph`/`twitter` (siteName,
  type website, description) in `app/layout.tsx`; keep per-page titles.
- **Favicon:** `app/icon.svg` — the brand mark (indigo `mcp`), served by Next.
- **OG image:** `app/opengraph-image.tsx` via `next/og` `ImageResponse`
  (built-in, no dep) — a branded 1200×630 card; `app/twitter-image.tsx` reuses it.
- **robots:** `app/robots.ts` — allow all, point at the sitemap.
- **sitemap:** `app/sitemap.ts` — the public routes (`/`, `/docs` + built doc
  pages from `_nav.ts` DOCS_ORDER, `/faq`, `/privacy`, `/terms`, `/security`).
  Exclude dashboard/auth routes.
- **manifest:** `app/manifest.ts` — name, theme color (`#4F46E5`), icon.
- **Errors:** `app/not-found.tsx` (branded 404) + `app/global-error.tsx`
  (top-level boundary with its own html/body). The `(app)/error.tsx` already
  covers the dashboard group.
- **Dangling refs:** already reconciled (Quickstart links `/docs/consent-levels`;
  remaining "Settings" refs are Claude's own settings + the digest-email mock).

## Files to create/modify

- `web/src/app/{icon.svg,opengraph-image.tsx,twitter-image.tsx,robots.ts,sitemap.ts,manifest.ts,not-found.tsx,global-error.tsx}` (NEW)
