# W5.1 — Trial → $5 conversion funnel + checkout

**Epic:** Web / public site (commercial v1)
**Estimated effort:** ~3 h

> Web-track card, branch web-v1. The money path: 7-day trial → checkout for the
> $5/mo plan → billing management. The web owns the funnel UX; the Stripe
> session/webhook is a server gap (carded as S7.1 for the server loop).

## Goal

Build the conversion funnel against the `src/lib/api` seam: trial-state nudges,
a pricing→checkout flow that redirects to the Stripe URL, `/account/billing`
success/cancel return states, and a billing-portal entry. Degrade honestly
while the Stripe backend is absent (fixtures return `url: null`). Add a
standalone `/pricing` page. Card the exact server contract.

## Spec

- **Checkout:** `/account/billing` "Start subscription" →
  `createBillingSession('checkout')` → **safe redirect** to the returned URL.
  Safe-redirect guard: only navigate to `https://` URLs on a Stripe host
  allowlist (`checkout.stripe.com`, `billing.stripe.com`) — closes the W1.1 P3
  (`window.location.assign` sink). Portal: `createBillingSession('portal')`.
- **Return states:** billing page reads `?checkout=success|canceled` and shows a
  confirmation or a calm "checkout canceled" note. (Server sets Stripe
  success_url/cancel_url to `/account/billing?checkout=…` — in the S7.1 contract.)
- **Trial nudge:** on the billing page, when `status==="trial"`, a clear "trial
  ends in N days — subscribe to keep your pipeline" state with the primary CTA.
  Sidebar trial line already present.
- **Fixtures honesty:** with no Stripe backend, checkout/portal return `null` →
  a plain "billing isn't wired up in this preview (S7.1)" note; nothing pretends
  to charge.
- **`/pricing`:** standalone page reusing the pricing content (self-host free /
  hosted $5 after 7-day trial); nav "Pricing" points to it.
- **No new dependency.**
