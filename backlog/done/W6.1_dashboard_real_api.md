# W6.1 — Dashboard against the real API

**Epic:** Web / dashboard
**Estimated effort:** ~3 h

## Goal

The dashboard shipped on fixtures (W1.1); S6.6a/b/c built the parity API and
S6.8 live-wired compose. This card makes the dashboard run against the REAL
API end to end: humanize ISO timestamps client-side, real empty-state
rendering, and fix any seam drift between `types.ts`/`http.ts` and the
shipped API. Browser-verified against the compose stack.

## Spec

- Audit every `Api` method (`web/src/lib/api/types.ts`) against its `http.ts`
  call and the real route in `entrypoints/api/app.py`: method, path, request
  shape, response shape. Fix drift on the side that is wrong (the API is the
  contract of record for fields it owns; the web for render-only concerns).
- ISO-8601 timestamps from the API are humanized at render (e.g. "2 h ago"),
  never raw ISO in the UI. If a shared `timeAgo` helper does not exist, add
  one small module (rule of two: used by ≥2 surfaces) with unit tests.
- Empty states: with a fresh DB the dashboard renders honest empty states
  (no phantom fixture rows, no crashes) on pipeline, matches, audit,
  sessions, connection.
- `npm run test` + `tsc --noEmit` + build green; no-LLM-deps guard green.
- Browser verification against `docker compose up` (the W6.1 demo gate):
  login via redeem link from `docker compose logs api` → real (empty)
  pipeline at :2200, no fixtures.

## Improvements noted

- Seam contract documented in `types.ts`: ISO-8601 across the wire, humanized
  at render via `web/src/lib/time.ts` (`timeAgo`, `now` injectable). Fixtures
  migrated to the same contract (`isoAgo`) so both adapters behave alike.
- `timeAgo` passes unparseable input through unchanged — a render must never
  crash on a bad timestamp; tested, incl. psycopg `+00:00` offset shape.
- Billing page + sidebar trial line branched on `price === "self-host"`;
  hosted copy unchanged for the future hosted track.
- Browser-verified against `docker compose up` (fresh volume): magic-link
  login via `docker compose logs api` → 302 to :2200/pipeline → empty
  pipeline with honest empty states; billing $0 self-host card; data page
  empty-audit state; sessions list with humanized lastSeen; export endpoint
  returns all 11 per-user tables incl. sessions.
- Evidence at close: web `node --test` 10/10 (9 timeAgo + 1 safeRedirect) ·
  `tsc --noEmit` clean · `next build` green · no-LLM-deps guard OK ·
  `uv run pytest` full suite 395 passed (web-only diff).
