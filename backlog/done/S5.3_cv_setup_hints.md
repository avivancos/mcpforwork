# S5.3 — CV-first setup + setup_hints (hybrid)

**Epic:** Self-host onboarding
**Estimated effort:** ~2 h

## Goal

Extend zero-LLM `parse_cv` with evidence-only `setup_hints` (work modes,
employment types, top allowlisted skills, signals) and invert `/setup` to
CV-first so the client LLM proposes titles/seniority/sectors from `cv_text` +
hints; the human CONFIRMs before any profile write. Server never invents and
never calls an LLM.

## Spec

- `extract_profile_from_cv` returns `setup_hints`:
  `{work_modes, employment_types, skills_top, signals}` — empty lists when
  unknown; never invent seniority/country/salary/titles on the server.
- Modality keywords map only to existing WorkMode / EmploymentType enums;
  B2B/invoice → `signals` only.
- Skills: frozen allowlist (~40–60), whole-word frequency, top 12.
- Bounded regexes; `MAX_CV_CHARS` unchanged; pure stdlib.
- `parse_cv` remains read-only; guidance + `/setup` prompt are CV-first.
