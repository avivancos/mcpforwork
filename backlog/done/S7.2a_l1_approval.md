# S7.2a — Autopilot L1: dashboard approval writes consent

**Epic:** Autopilot / consent
**Estimated effort:** ~4.5 h

## Goal

L1 autonomy: a human approves a specific application's submit from the
dashboard (human-session HTTP API), and `request_submit` turns that recorded
approval into a one-time `submit_authorized`. The load-bearing design is
ADR 0005: **consent artifacts are written exclusively by the human-session
HTTP API, never by the MCP entrypoint** — no sequence of MCP tool calls
(possibly prompt-injected by posting content) can mint consent.

## Spec

- **ADR 0005** (`backlog/decisions/0005_consent_writes_api_only.md`):
  consent artifacts (L1 approval now, L2 policy in S7.2b) are written only by
  the session-authenticated HTTP API; MCP tools are read-only over them.
  `STEP_KINDS` never gains `"submit"` — authorization is a response-scoped
  directive from `request_submit` for an application in `submit_requested`,
  never a persisted plan step. Also update AGENTS.md §1.2 wording to "never
  submit without a recorded consent check".
- **Migration (both dialects):** `applications` gains `submit_approved_at`
  (timestamp, nullable) and `submit_approved_via` (text, nullable).
- **New route:** `POST /v1/applications/{id}/approve-submit` — session-auth,
  state-guarded (only an application in `submit_requested` can be approved;
  404 cross-tenant; structured error kinds per S6.10).
- **`request_submit` re-entry:** in state `submit_requested`, re-evaluate:
  with a recorded approval → emit `submit_authorized` **exactly once** per
  application, set `consent_level=1`, write audit row with
  `{approved_at, approved_via, snapshot}`. Without approval → `await_human`
  (current behavior, unchanged).
- **`confirm_submitted`** records channel `browser_autopilot_l1` when the
  submit followed an L1 authorization.
- **Consent suite evolution:** replace
  `test_no_source_path_yields_submit_authorized_this_sprint`
  (tests/test_consent_gate.py — written to die on this card) with:
  no approval → always `await_human`; API approval → authorized exactly once;
  inspect-source test that the MCP entrypoint never references the
  approval-write function.
- **CI consent grep extension:** approval/policy-write SQL may appear only in
  `services/autopilot.py` (new module) — extend the existing grep step.
