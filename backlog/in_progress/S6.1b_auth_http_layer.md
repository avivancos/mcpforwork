## Framework decision (needs user awareness)
ADR 0002 says "FastAPI", but **fastapi is NOT installed** (adding it pulls
fastapi+pydantic — a dependency-budget hit), while **Starlette 1.3.1 + uvicorn +
httpx are already transitive via `mcp`**. Build on **Starlette** (zero new runtime
deps; Starlette `TestClient` uses httpx → real zero-mock HTTP tests). Flag for the
user to override if FastAPI's validation/OpenAPI is wanted.

## This slice (prove the pattern end-to-end; later cards add the rest)
- `entrypoints/api/` Starlette app (`app.py`) + a `serve` runner (uvicorn).
- `ports/mailer.py` — a `Mailer` Protocol; a default console/log adapter that
  emits the magic-link URL (self-host single-user). Real provider = later card.
- Auth: a session-cookie helper reading `auth_session.read_session` → user_id;
  routes 401 without a valid cookie. `SESSION_SECRET` from env (fail-closed in
  prod if absent).
- Routes this slice:
  - `POST /v1/auth/magic-link {email}` → `auth_session.request_magic_link` +
    `mailer.send` (returns 202/204; NEVER leaks the token in the response body).
  - `GET /v1/auth/redeem?token=…` → `auth_session.redeem_magic_link` → set the
    signed session cookie (`Secure`, `HttpOnly`, `SameSite=Lax`) → `{ok}`/redirect.
  - `GET /v1/profile` → `profiles.get_profile` (authed).
  - `POST /v1/account/export` → `privacy.export_user_data` (authed).
  - `POST /v1/account/delete` → `privacy.delete_user_data(confirm)` (authed).
- Add the deferred **entrypoint-independence import contract** ("entrypoints never
  import each other") — `api` is now the 3rd entrypoint (mcp/cli/api), so the
  rule-of-two trigger from the S0/S2 gates is finally met.

## Decision: `/v1/account/delete` takes no confirm body
The test-auditor flagged the absent confirm gate. The web consumer
(`web/src/lib/api/http.ts` `deleteAccount()`) POSTs with NO body, and the
dashboard gates deletion with its own "type DELETE" modal — so the authed POST IS
the confirmation. CSRF is covered by `SameSite=Lax` now (cross-site POST omits the
cookie) + CSRF tokens next card; a body-confirm would break the contract without
stopping the real threats (XSS can send any body). Kept bodyless; documented.
